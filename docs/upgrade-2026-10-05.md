# Upgrade Notes: 2026-10-05

This public note summarizes the interface and application-management upgrade without private deployment evidence.

## Added

- Application minimum trust-level policy.
- Lite-only application mode.
- Public versus confidential application type.
- PKCE enforcement for public applications.
- Owner-visible confidential-client secret display and rotation.
- Seven-day application login records and audit views.
- Field documentation in application details.
- Simplified functional UI for login, application management, credentials, and records.

## Security and Privacy Boundaries

- Public clients do not receive a client secret.
- Confidential-client secrets are visible only to the owning user.
- Historical hash-only confidential-client secrets cannot be recovered; owners must rotate to make a secret repeat-readable.
- Upstream Connect secrets remain encrypted and are not re-displayed.
- Audit changes allowlist business fields and exclude secret values.

## Validation Boundary

The original private release included local tests, browser checks, staging checks, and production checks. Public docs intentionally omit local evidence paths, real user identities, domains, Cloudflare resource IDs, and deployment version IDs.

Use [validation.md](validation.md) for the current public validation status.
